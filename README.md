# 💎 מעקב פיננסי חכם

אפליקציית מעקב פיננסי אישית — צד-לקוח בלבד (SPA), ללא שרת וללא חשבונות. כל הנתונים נשמרים **מקומית בדפדפן** (localStorage), כך שאפשר לשתף את הקישור והמידע של כל משתמש נשאר פרטי על המכשיר שלו.

🔗 **חי באוויר:** https://arbel2103.github.io/finance/

## יכולות

### 📊 דף מעקב הוצאות חודשי
- טעינת קובץ אקסל של דוח אשראי (כאל/ויזה) — זיהוי אוטומטי של עמודות, תאריכים וקטגוריות.
- בורר חודש עם **נקודה ירוקה** לחודשים שכבר נטענו (מניעת טעינה כפולה).
- חלון קטלוג **העברות ביט** ("שונות") שקופץ מיד עם הייבוא, לסיווג מחדש לפני שמירה.
- קלפי סיכום: סה"כ הוצאות, מספר עסקאות, קטגוריה מובילה, ממוצע לעסקה.
- הזנת משכורת חודשית, הכנסות נוספות, והעברות בנקאיות (הוצאות לא באשראי).
- **טאב ריכוז ורשימה:** דיאגרמת עוגה (איחוד קטגוריות חכם) + רשימת הוצאות עם כפתורי שינוי קטגוריה, החזר, ושיוך למטרת חיסכון. לחיצה על פלח מסננת את הרשימה.
- **טאב מגמה חודשית** ו**מגמה לפי קטגוריה** עם בורר טווח זמן.

### 📈 דף מעקב הון והשקעות
- קלפי סיכום: סה"כ השקעות, חסכונות, עו"ש (קלף-כפתור לעדכון), וסה"כ הון.
- חשבונות (חיסכון/השקעה) עם מטרות חיסכון וחישוב חכם של הפקדה חודשית נדרשת ליעד.
- תיעוד השקעות חודשיות, גרף עמודות-ערימה לפי חשבון, גרף אחוז מהמשכורת, והיסטוריה.

## טכנולוגיות
React · Vite · TypeScript · Tailwind CSS · Zustand (persist) · Recharts · SheetJS

## פיתוח מקומי
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # בנייה לפרודקשן (ל-/finance/)
```

> כל הנתונים נשמרים ב-localStorage של הדפדפן בלבד — אין שרת ואין שיתוף נתונים בין מכשירים.
